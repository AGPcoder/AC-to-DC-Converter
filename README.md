# AC to DC Converter PCB

## Overview

This project is an AC-to-DC converter PCB designed using **EasyEDA**.

The circuit converts AC input into a regulated DC output for powering electronic circuits.

## Main Features

* AC input and protection
* Bridge rectifier
* DC filtering
* Voltage regulation/conversion
* Output filtering
* Protection circuit
* 2-layer PCB

## Project Files

* **3D Image** – PCB 3D images
* **BOM** – Bill of Materials
* **EasyEDA Files** – Schematic and PCB source files
* **Gerber** – PCB manufacturing files
* **Design Notes** – Design documentation
* **Pick and Place** – Component placement files

## Software

* EasyEDA

## Safety

**Warning:** This project may operate at hazardous mains voltage.

Proper isolation, creepage and clearance, fusing, and electrical safety precautions must be followed during testing and operation.
